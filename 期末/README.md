## ✨ 已實作的完整功能

1. **三大分類管理**：
   - 💻 **一般網頁**：專門收納 GitHub 開源倉庫、技術文件、工具網站。
   - 🎬 **影音影片**：專門收納 Bilibili、YouTube 影片或串流，具備封面預覽。
   - 📦 **動漫資源**：專門收納巴哈姆特動畫瘋、漫畫線上看、ACG 資料庫與推薦站。
2. **直覺的搜尋與即時篩選**：
   - 支援搜尋標題、網址關鍵字、備註描述或標籤。
   - 快捷鍵：在網頁上直接按下鍵盤鍵 `/` 即可快速聚焦搜尋框。
   - 支援依「分類標籤（全部 / 網頁 / 影片 / 資源）」快速切換。
   - 自動提取所有收藏的標籤（Tags），生成即時標籤篩選晶片。
3. **多維度排序與視圖切換**：
   - 支援依「最新收藏」、「最多跳轉 (人氣熱門)」、「標題名稱 (A-Z)」、「置頂優先」即時排序。
   - 支援「卡片瀑布流 (Grid)」與「緊湊清單 (List)」兩種瀏覽視圖切換。
4. **完整收藏管理 (CRUD)**：
   - **新增 / 編輯**：彈出式視窗，輸入網址提供「智慧辨識」按鈕，可自動偵測網址來源並預設分類與標籤。
   - **一鍵跳轉**：點擊「前往網頁」開新分頁直達目標網站，並即時累計「跳轉次數」。
   - **置頂功能**：星號圖示一鍵將重要網站固定於頂部。
   - **本地存儲 (LocalStorage)**：即使尚未連接資料庫，所有的增刪查改操作都會完整保存在瀏覽器中，重新整理也不會遺失！
5. **備份與示範重置**：
   - 右上角使用者選單提供「匯出書籤 (JSON)」下載備份。
   - 提供「重置範例資料」按鈕，方便隨時復原初始展示效果。
6. **篡改猴 (Tampermonkey) 採集助手**：
   - 附帶 `tampermonkey/web-library.user.js` 腳本。
   - 支援右下角懸浮按鈕或快捷鍵 <kbd>Alt + B</kbd>，於任何網頁一鍵抓取標題與網址。
   - 主介面右上角提供「篡改猴插件」導引彈窗，內含「模擬採集」按鈕供課堂展示。

## 🚀 如何開啟測試

1. 直接使用滑鼠連點兩下開啟 `index.html`，即可在任何瀏覽器中體驗！
2. 亦可在 VS Code 中透過 Live Server 外掛開啟，或透過 Node.js 執行靜態伺服器。
