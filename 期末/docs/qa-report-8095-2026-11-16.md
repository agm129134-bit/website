4 個代理各自用 headless Chrome＋curl 測 http://localhost:8095，分成登入帳號、首頁收藏、ACG 專區、伺服器 API 四區。

相關 commit：`9596fd2`（高）、`e79eafc`（中）、`d7acd45`（安全強化）、`020582f`（低，Antigravity 實作）、`46fd720`（剩餘小問題）。

## 高優先

| # | 問題 | 修法 | 狀態 |
|---|------|------|------|
| H1 | 畸形 Host 標頭（如 `Host: a b`）讓整個 Node 程序崩潰 | 各 API 改用固定 URL base；server.js 統一接住路由例外，並加 `unhandledRejection` 防線 | ✅ |
| H2 | `onclick="f('${escapeHtml(x)}')"` 跳脫無效：`&#039;` 會被瀏覽器還原，可注入 JS；含 `'` 的標題會讓按鈕失效 | 新增 `jsArg()`（JSON.stringify＋escapeHtml），所有 onclick 字串參數改用它 | ✅ |
| H3 | 匯入 JSON 的 `clicks`、`url`、`id` 未驗證，形成持久型 XSS 並同步到伺服器 | 匯入與伺服器端都強制轉換欄位型別，只接受 http(s) 網址；favicon 和點擊數輸出都先跳脫 | ✅ |
| H4 | 登出不清自訂來源規則，下一個登入者會看到並上傳到自己帳號 | 規則記錄 `owner`，不是目前帳號的規則不載入；登出時清除 | ✅ |

## 安全項目

| 項目 | 狀態 |
|------|------|
| SSRF：IPv4 相容 IPv6（`[::127.0.0.1]`）、6to4（`2002:7f00:1::`）、Teredo 可繞過 | ✅ 已補上 |
| 路徑穿越、`.env`／資料庫／`.git` 下載、404 頁反射型 XSS | ✅ 重測全擋 |
| 未登入或假 token 存取帳號 API | ✅ 全回 401 |
| 外部網站冒用身分操作 Docker API（CSRF、DNS rebinding） | ✅ 有 Origin、`Sec-Fetch-Site`、Host 檢查 |
| `/api/kazumi`、`/api/manga`、`/api/novel` 不需登入（對外開放時可被當抓取代理） | ⏸️ 8090 訪客展示需要；8095 若要對外開放再改 |
| 有設 `DOCKER_OWNER_USER` 但帳號還沒註冊時，可被搶先註冊 | ⏸️ 8095 的 Docker API 本來就停用 |
| `verifyPassword` 對舊資料用明文比對 | ⏸️ 只影響很早期的帳號 |
| `api/kazumi.js` 先查 DNS 再用 fetch 連線，兩者之間有時間差（DNS rebinding） | ⏸️ 原生 fetch 無法自訂 DNS 查詢 |
| 8095 若所有請求顯示同一個來源 IP，速率限制會變成全站共用 | ⏸️ 最壞情況是 10 分鐘內無法登入；勾選「記住我」的登入不受影響 |
